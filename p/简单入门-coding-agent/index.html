简单入门 coding agent

这篇文章的目标读者是初级工程师和计算机类专业的本科生。

coding agent 不是最近才火起来的，但是不少小伙伴还不知道怎么使用 coding agent。

这里，我写一篇文章，来讲讲如何入门 coding agent。

本文对读者要求：

  1. 知道命令行是什么，可以打开终端。
  2. 计算机专业背景，工程师。

coding agent 受到大家的广泛喜爱。很多人被 coding agent 这个名词吓到了，但其实入门其实很容易。现在我比较推荐 oh-my-pi 和 kimi code 这两个 coding agent，就以这个 agent 为例，讲讲如何使用。

安装

我建议把这个问题直接问 DeepSeek。例如 如何安装 omp (oh-my-pi) 和 kimi code。照着命令敲就行了，非常方便。

使用

安装完成后，你可以通过使用 omp 命令进入 oh-my-pi，或者输入kimi web --host来运行 kimi code。

我现在比较推荐 kimi code。因为如果你使用 kimi code 可以有一个图形化界面来操作。你可以把这个命令跑在 Linux 终端上，就可直接在自己的服务器上跑 kimi code 了。所有的命令执行都不会影响你的本地机器，也会从物理上隔离你的数据。

在服务器上跑

你可以直接在腾讯云购买一个轻量应用服务器做这个事情。如果你已经学会使用 Linux 服务器了，我建议你看看我的这篇文章来调整一下自己的服务器。我认为不做过多配置，就是最好的配置方式。

PS: Linux 真的不适合 GUI。也就是说，Linux 不适合作为自己的桌面机器。要么使用 Windows，要么 macOS，别给自己找罪受。
