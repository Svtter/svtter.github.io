Coding With Cloud Server

程序开发经常会让本地机器卡顿，尤其是编译某些较大文件的时候。除此之外，如果涉及到数据集处理，会带来更多麻烦，例如下载数据动辄10G，部署环境不一致导致包冲突问题。更重要的是，可以在 windows 上使用 linux 生态，而不用切换操作系统，或者购买昂贵的 Macbook。

因此，如果只进行 web 开发，或者数据应用相关的，那么云服务器是一个相当不错的选择。 云服务器现在价格很优惠。经过本人测试，腾讯云轻量服务器相当靠谱。可以直接搞定基本问题：公网ip，带宽，存储，服务器本体。

这个是我的推广链接，可以直接跳转购买。

当然，如果本地有服务器或者虚拟化的主机，直接在本地创建新的 Debian 服务器来链接配置，其实更好用。

如何做

这个插件可以让我们通过 ssh 连接到服务器，并且自动开放端口，从本地的链接，例如 127.0.0.1:1080 进行访问。可以在 port 中看到。

通过这样的方式，调试也变得容易了。你可以直接启动数据库等服务，不用在本地配置复杂的环境。

总结

总结一下，有几个好处：

  • 性能占用都在服务器上，本地机器运行通畅。
  • 依赖简单，linux 系统；环境独立，一个项目一个环境，或者少量的项目一个环境，不容易破坏依赖。
  • 重装容易，一键重装。
  • 不需要担心垃圾文件问题，可以备份后直接重置系统。
