Token Plan 性价比分析

对比了MiniMax、小米、Deepseek、Kimi和GLM等大模型供应商的套餐性价比，结果显示小米最划算。

我订阅了几个大模型供应商，现在算一算性价比，给大家伙做参考。

订正：2026年7月8日。GLM MAX 套餐应该是 2.88 元/亿 token。我之前计算的时候将 B 按照亿来计算了，应该是 10亿。
