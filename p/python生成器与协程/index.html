import time
def loop():
    ser = "test"
    command = ''
    print '[loop] run loop...'
    while True:
        command = yield ser
        if command == '':
            print '[loop] run something...'
        elif command == 'change':
            ser = "[loop] test_change"
        else:
            ser = "[loop] stop"
            break
    yield ser

协程这个特性相比仅仅使用生成器，有一个很神奇的地方，就是多出一个Send方法，将

yield这个操作返回值，使得生成器可以接收数据，并将这个数据通过yield返回生成器

内部。通过这个方法，可以比较巧妙地把一些参数扔进已经处于循环状态的函数，而不

需要使用别的类似于signal的变量，十分方便。
